# iAdmin

A small PHP + MySQL admin framework: describe a table in a module `config.php` and get list, filter, sort,
add / edit / delete, inline edit, bulk actions and export pages, with per-role rights, a dashboard and templates.

- Requirements: PHP 8.1+, MySQL 5.7+ / MariaDB 10.3+, Apache with mod_rewrite.
- Install: open the site, the setup wizard (`setup/`) creates the database tables and `settings.ini`.

Documentation: [docs/](docs/README.md) — installation, architecture, modules, field types, rights, templates,
security, developer reference, database, libraries.
